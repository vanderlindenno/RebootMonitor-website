Configure RebootMonitor with an Intune app configuration policy

Set the reboot reminder for every device from one place, let Intune grant the notification permission, and hide the settings and website buttons with a license key.

View on Google PlayFree app · License only for the hide options

What the policy does

From version 1.21 an app configuration policy sets the reboot reminder on every device from one place. With a license key (from version 1.22) it can also hide the settings button and the website button, and show your organization's name in the app.

This guide is about the optional policy. To roll the app out to your shared devices first, follow the Intune deployment guide.

The app reads the policy on the device, without any extra permission or network connection, and nothing leaves the device. Without a policy the app works exactly as before.

What the user sees

  • When the reminder is set by policy, the reminder choices in Settings show the value that applies but are greyed out, under the note “Managed by your organisation”. A setting you leave out gets the app default (on, 7 days).
  • The user's own choice stays saved and returns if you remove the policy. A change in Intune applies at once while the app is open, and otherwise the next time it is opened.
  • Without a valid license key, Hide settings and Hide website button do nothing: the buttons stay, and Settings says why. The reminder settings work either way.
  • With a valid license key the information screen shows your organization's name in place of the donation link.

Set it up in Intune

  1. Create the policy

    Go to Apps › App configuration policies › Add › Managed devices. Platform: Android Enterprise. Profile type: Fully Managed, Dedicated and Corporate-Owned Work Profile (for shared devices and kiosks), or Personal Work Profile.

  2. Pick the app

    Targeted app: RebootMonitor.

  3. Grant notifications (optional)

    Under Permissions choose Add, pick Post notifications and set it to Auto grant. More below.

  4. Add the settings

    Choose Use configuration designer and add the settings you want, or choose Enter JSON data and paste the example below.

  5. Assign it

    Assign the policy to the same device group as the app.

{
  "kind": "androidenterprise#managedConfiguration",
  "productId": "app:app.rebootmonitor.mobile",
  "managedProperty": [
    { "key": "reminder_enabled", "valueBool": true },
    { "key": "reminder_days", "valueString": "7" },
    { "key": "license_key", "valueString": "RM1.…your license key…" },
    { "key": "hide_settings", "valueBool": true },
    { "key": "hide_website", "valueBool": true }
  ]
}

Menu names can differ a little between Intune versions. Leave out license_key, hide_settings and hide_website if you only want to set the reminder.

Let Intune allow notifications

The reminder is a notification. From Android 13 an app has to ask the user for permission to show notifications, and a user can say no. On managed devices you can grant that permission centrally, so the user is not asked and a reminder cannot be missed because of a refused prompt. There are two ways.

Option 1: for RebootMonitor only (recommended). In the app configuration policy above, add Post notifications under Permissions and set it to Auto grant. A permission granted there overrides the default permission policy and applies to this app only.

Option 2: for all apps. A device restrictions profile can set the default permission policy for every app in the work profile:

  1. Create a profile

    Go to Devices › Configuration › Create. Platform: Android Enterprise. Profile type: Device restrictions, under Fully Managed, Dedicated and Corporate-Owned Work Profile (or Personal Work Profile).

  2. Auto grant permissions

    Under General, set Default permission policy to Auto grant. Android then grants the permissions an app asks for without showing the prompt, including notifications.

  3. Show system notifications

    Set System notifications and information to show them in the device's status bar. On a kiosk with Managed Home Screen, also keep the notification bar available there.

  4. Assign it

    Assign the profile to the same device group as the app, and test it on one device first.

Good to know. The permission is granted the first time the app asks for it, so open the app once after the profile arrives. A user who already refused notifications earlier is not overruled by this setting: reinstall the app or reset that device. With option 2, Default permission policy applies to all apps in the work profile, not only RebootMonitor. Before Android 13 notifications are on by default and nothing is needed.

About the license key

  • One license per organization, with no end date: it does not expire. The price depends on the number of devices and is given on request.
  • The key carries your organization's name, not a list of devices, and is checked offline inside the app. There is no license server and no data is sent.
  • You paste the key into the License key setting of the policy. If the key is missing or wrong, the two hide settings simply have no effect.

Price on request. The price depends on the number of devices. Use the contact form on the home page and tell us the name of your organization and roughly how many devices you manage. We reply with a quote, and send you the key to paste into the policy once the license is arranged.

If you hide the settings, manage battery optimization from the device side. Users can no longer open the battery optimization shortcut from the app. On Samsung devices, deploy the Samsung Knox Service Plugin (OEMConfig) through Intune and use its battery optimization settings to exempt RebootMonitor (package app.rebootmonitor.mobile) across the whole fleet. For other brands, use the manufacturer's OEMConfig app where it offers such a setting. That way background reminders stay reliable without any action from the user.

Frequently asked questions

Can I set the reboot reminder from Intune?

Yes. From version 1.21 an app configuration policy can turn the reminder on or off and set it to 3, 7 or 14 days for every device. Users then see the value that applies, greyed out in Settings, under the note that their organization manages it. The settings are read on the device, so no extra permission or network connection is needed.

What does the license key do, and what stays free?

The reminder settings and the whole app are free. A license key is only needed to hide the settings button and the website button with an app configuration policy. A valid key also shows your organization's name in the information screen, in place of the donation link. Without a valid key the two hide settings do nothing and the buttons stay visible.

How do I get a license key, and what does it cost?

Use the contact form on the home page and tell us the name of your organization and roughly how many devices you manage. The price depends on the number of devices and is given on request. The key is one-time, has no end date and is checked offline in the app, so no data is sent anywhere. Paste it into the License key setting of the app configuration policy.

Can Intune allow notifications for RebootMonitor so users are not asked?

Yes, on Android 13 and later. The simplest way is to add Post notifications under Permissions in the RebootMonitor app configuration policy and set it to Auto grant, which applies to this app only. Alternatively, set Default permission policy to Auto grant in a device restrictions profile, which applies to all apps in the work profile. Android then grants the notification permission the first time RebootMonitor asks for it, without a prompt. See the steps.
